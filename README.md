# Halaqi Chairside Bookings

Build a mobile-friendly Arabic web app called "حلاقي" for barbers and their customers.



Use Arabic language and right-to-left (RTL) layout.



Create these pages:



1. Home page with the app name and two large buttons: "أنا حلاق" and "أنا زبون".

2. Barber dashboard to manage appointments, customer names, debts, and payments.

3. Customer page to enter a barber code, view available time slots, and book an appointment.

4. Appointment list with date, time, customer name, and booking status.

5. Debt records showing amount, payment status, date, and time.



Use a clean, professional design that works well on Android phone screens.



Start by building the user interface and navigation. Do not claim that login, database storage, booking conflict prevention, or notifications work until they are implemented and tested.
